**The field is not a computer merely because it is recorded.** Work must be distinguished:

1. **Digital computation of physical observations:** software evaluates data coming from a field. This exists in design, the current owner implementation uses synthetic data.
2. **Physical processing as a circuit element:** material fields perform a controlled, repeatable, quantified transformation (e.g. impedance-dependent routing of a weak test signal). NOT RUN.
3. **Physical processing as memory or logic:** a specific physical material state materially contributes a repeatable state transition, conditional memory or logic operation that changes a downstream computational result, with controls and independent verification. NOT RUN.
4. **Interoperable physical computer:** multiple qualified sensors/physical processing organs and sovereign runtimes exchange provenance-bound results over permitted media; humans retain authority. NOT RUN.

## Proposed experiment order

**CF0 — Software organ:** exact STATIC-OS code, 19 focused hostile tests, cold source withdrawal, no hardware I/O and no public discovery.

**CF1 — Two room sessions:** two human-chosen player-state sources, opt-in, revocable temporary aliases, no microphone permission, separate session consent and no automatic connection.

**CF2 — Physical sound/light:** one actual recorded song cue and one optical sigil plus *independently retained raw* local measurements; calibration and false-positive controls.

**CF3 — Soil/copper/wiring:** isolated battery-powered low-voltage bench fixture. Measure noise, attenuation, electrical input/output and moisture dependence. Never attach a homemade circuit to utility wiring, telecom plant or high-voltage Tesla apparatus. Certified power-line adapters are a different, explicitly authorized network experiment.

**CF4 — Field logic test:** a predeclared task whose input-output behavior requires a measured material transfer function or stateful component, versus a software-only baseline. Vary one physical condition and retest under identical input; quantify errors, power, drift, and reconstructibility. If the material only tags weather, do not claim analog/environmental computation.

**CF5 — Multi-body:** two autonomous local hosts with replaceable sensing organs and finite signed message courier, with radio/light/phone adapters only after real hardware and operator-permission witnesses. Local HOLD remains local; physical transport confers no admission.

**CF6 — Public human encounter:** Abundent dial interface offers opt-in temporary room relationships without exposing raw domestic audio, precise location or permanent fingerprints.
