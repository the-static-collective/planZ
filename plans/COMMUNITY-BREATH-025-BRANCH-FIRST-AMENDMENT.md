## Human correction
Most root READMEs are stale; most of our substantive code is on nondefault branches. A repository listing and default README census undercount actual work, and must not be used to declare architectural maturity.

## Reconciliation
The original CANNON 025 generated a 102-address inventory with 26 inspected README blobs. This was a **discovery list**, not a current implementation survey. That limitation is now material and explicitly acknowledged.

CANNON 025 independently enumerated **2,132 Git branch refs across the 102 accessible candidate repositories**, including **2,031 nondefault refs** and **70 repositories with one or more nondefault refs**. GitHub branch pagination completed for all 102. This proves reference existence only; no count of active, safe, deployed, usable or mergeable branches has been established. Full evidence stored in `CANNON/labs/living-commons-001/branch-evidence-00..10.json`, the Haunted Toaster continuation, and `branch-frontier-index.json`. Comparison-to-main of selected current branches in CANNON, planZ, WITNESS, static-field, webZ and Haunted Blender revealed substantial work invisible from default READMEs.

## Revised order
1. Preserve exact branch addresses and commit heads. Do not delete, rebase, merge or promote anything merely to simplify the picture.
2. Group by actual changed files and source-native architecture, not naming resemblance or README topic tags.
3. Follow PR and ancestry relationships, including stacked branches, contested alternatives and detached historical work.
4. Test *one* promising runnable slice locally. Store exact toolchain, failure/verification evidence and observed date.
5. Invite relevant community stewards to articulate their own needs and permissions. No automatic Coalition/Waseca/Real Life partnership claim.
6. Make a paper-first OFFER/NEED/BUILD encounter possible independent of software. Let its explicit human outcome choose a future technical organ.
7. Propose owner-reviewed, typed adapters one at a time. Keep the CARE and CULTURE permission streams independent and the source authority local.
