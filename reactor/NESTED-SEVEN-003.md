# NESTED-SEVEN-003 — The first PlanZ output becomes the enclosing cycle

The original PlanZ source plan is not replaced or promoted. A new, immutable **root planning cycle** explicitly references that original source ID and encloses the entire seven-source-creative-engine software experiment as seven nested, independently inspectable child cycles.

Each source-owned creative engine is recorded as a child of the original root; each child's first planning pass is the **actual** original PlanZ RETURN-SEVEN-002 four-lens proposal (four unique cuts and one plan). That child can itself contain a bounded second or third pressure-pass cycle using the real original PlanZ lens definitions.

**Default depth 2:** one root → seven original native-software-evidence child cycles → seven distinct second-generation planning-only grandchildren. 14 linked cycle records, 56 lens cuts (28 original evidence-return cuts plus 28 new hypothetical reviews), 14 held candidate plans (7 evidence-return plans plus 7 new hypothetical reviews). Native creator engines do **not** get executed a second time for those second-generation descendant reviews. The historical software-output digest is inherited with that distinction explicit.

CLI:

    node reactor/nest-seven.mjs --source-dir /tmp/one-invention-held --return-dir /tmp/planz-return-held --out-dir /tmp/planz-nested-held --depth 2

The program first uses the **original PlanZ seven-return compiler** to revalidate all CANNON source file digests, exact seven owner identities, original PlanZ source and original Workbench board. It then verifies that the supplied *saved original PlanZ returned ledger* matches exact independently regenerated bytes for all 28 cuts, 7 plans and manifest. Reused software experiment observations are not upgraded to genuine physical field outcomes by later planning passes.

Outputs: `tree.json` physically contains the nested tree, `manifest.json` preserves a content-addressed full flat ledger, each cycle, cut and plan lives in separate files, and `exhibit/index.html` is a browsable nested root/child/grandchild planning notebook. The original creative exhibition is a sibling source and is linked separately.

Limits: depth must be an integer 1–3. Each added level adds seven HELD plans and 28 HELD angle cuts. No unbounded agent loop, autonomous execution, approvals, persistent source changes, source-origin rewriting, publishing or physical work. The seven initial creative owner outputs have actually run upstream, but **not again** here; this project is the planning compiler, not the native creative executor.

The original first plan keeps its identity, and all descendants remain children with independently preserved history. Nothing overwrites the original seven plans.

**Root identity != owner approval. Planning descendant != verified machine.**
