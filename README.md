# planZ

**Global plan census, archaeology, and disposition for the Static Collective.**

planZ exists to answer one bounded question:

> **What did we say we would do, what became of it, and what—if anything—still remains?**

This repository is not a master authority over project-local plans. It is a provenance-preserving index and recovery surface.

The first full census is being developed as **PLANZ-001**.

## Experimental network crossing — HEAP-CUT-001 (draft only)

The [Living Neighbor Network master shard](grand-shards/2026-10-21-the-living-neighbor-network-001.md) asks whether one whole community food/neighbor network can move through planZ as an attributable, consent-governed proposal—from local source cards, to optional human-edited radio, to a current-state public website/listening-app portal, to independently confirmed human return.

The [HEAP-CUT-001 bench](heap-cut/README.md) holds the schematic network map, rotating fictional Kinship bulletin, Kinship web/app portal mockup, source-linked passport and synthetic tests. These artifacts are **DRAFT / HELD**: no store, aid program, Kinship Radio partnership, actual broadcast, web/app integration or real-world delivery is asserted.

This proposal does not supersede PLANZ-001 or the repository's project-local authority boundaries. It demonstrates one possible **source-linked future with explicit refusal and proof gates**.
