# planZ

**Global plan census, archaeology, and disposition for the Static Collective.**

planZ exists to answer one bounded question:

> **What did we say we would do, what became of it, and what—if anything—still remains?**

The process itself is part of the artifact.

```text
discover
→ gather
→ normalize
→ trace descendants
→ classify present disposition
→ state remaining edge
→ audit coverage
→ maintain deltas
```

## Governing law

> **Gather every attributable plan. Follow every promised edge. Name what happened. Leave no unclassified future behind.**

planZ is an index and recovery surface. It does **not** become authority over project-local plans.

## Critical distinction

```text
PLAN COMPLETE AS HISTORY
    ≠
PLAN IMPLEMENTED
    ≠
PLAN LANDED
    ≠
PLAN STILL DESIRABLE
```

PLANZ-001 is complete when every discovered plan in the declared census scope has provenance and a present disposition—even if that disposition is HOLD, ABANDONED, SUPERSEDED, or UNKNOWN.
