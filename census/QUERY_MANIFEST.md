# PLANZ-001 Query Manifest v0

This file freezes the minimum discovery procedure for the first global census.

## Repository census

Enumerate every accessible repository in the-static-collective and preserve the exact repository list in the dated scope receipt.

## Per-repository branch census

Enumerate all discoverable branches. Do not restrict the census to default branches.

Flag branch-name families including plan/, design/, docs/, feat/, feature/, experiment/, experimental/, research/, slice/, archive/, rescue/, reconcile/, integration/, flight/, and lighthouse/.

Branch names are candidate signals only.

## File search vocabulary

Search plan-bearing text and filenames using at least: plan; implementation plan; roadmap; next step; next slice; future work; TODO; proposed; acceptance criteria; required work; first executable; first proof; design only; docs-only; implementation remains; not implemented; pending; deferred; handoff.

Prefer exact named artifacts when a plan provides them.

## Collaboration surfaces

Search open PRs, closed PRs, merged design-only PRs, closed-unmerged implementation/design branches, open and closed issues, and plan/design/handoff commits.

## Descendant pressure

For every candidate, search forward for exact plan names, planned module/function/file names, successor PRs, implementation/reconcile/re-port branches, and later repositories containing the same distinctive law or schema vocabulary.

Negative search evidence is useful only when the query is specific enough to matter.

## Classification discipline

Do not classify from age alone, open/closed state alone, merge state alone, unchecked Markdown boxes alone, or name similarity alone.

A current disposition requires source + descendant evidence.

## Final re-scan

When the registry appears complete, rerun this manifest against the frozen repository scope and classify every newly found candidate before closing PLANZ-001.
