# PLANZ-002 Maxhinals

## Instrument species

A Maxhinal is a bounded deterministic mutation chamber operating over census-grounded material.

It is not a persona and not an autonomous planner.

```text
fuel
→ declared chamber
→ candidate
→ residue
→ receipt
```

Every chamber receives:
- exact source PlanRecord refs;
- exact SenseFrame refs;
- declared parameters;
- the current census cut identity.

Every chamber emits:
- candidate mutation or explicit refusal;
- source ancestry;
- chamber identity;
- residuals;
- `authority: none`;
- `selection: NONE`.

## REANIMATE

Use when:
- present disposition is STRANDED or PARTIAL;
- recovery mode is RESURRECT.

Question:

> What is the smallest continuation that uses the surviving body without pretending old state is current state?

Output:
- continuation candidate;
- freshness checks still required;
- explicit no-wholesale-merge posture.

## RECONSTITUTE

Use when:
- implementation evidence exists;
- current authority has materially diverged;
- recovery mode is REPORT.

Question:

> What proven behavior should be re-expressed on current authority, and what historical ancestry should remain evidence only?

Output:
- re-port candidate;
- donor refs;
- destination authority ref if supplied;
- unresolved compatibility seams.

## GRAFT

Use when:
- a plan is REINCARNATED;
- recovery mode is RECOMPOSE;
- one organ/law remains useful.

Question:

> What can cross without carrying the dead body's obsolete authority or architecture?

Output:
- organ candidate;
- explicit retained law;
- explicit discarded ancestry;
- recipient remains separately owned.

## PROBE

Use when:
- disposition or desired continuation is UNKNOWN;
- recovery mode is INVESTIGATE.

Question:

> What is the smallest observation that would materially reduce the uncertainty?

Output:
- one bounded probe;
- expected discriminating outcomes;
- no forced next action.

## PRESSURE

Use on a candidate.

Question:

> What would make this mutation wrong, redundant, unsafe, already satisfied, or unnecessary?

Output:
- hostile tests;
- counterpressure;
- possible refusal.

## CROSS

Use only when an explicit hinge is supplied.

Question:

> If these two plans are allowed to meet at this one declared seam, what bounded third candidate becomes possible?

Required:
- two exact plan IDs;
- explicit hinge text or hinge receipt;
- both ancestries retained.

Forbidden in v0:
- similarity-driven automatic pair generation;
- inferred shared intent;
- silent authority composition.

## PRUNE

Use when there is an explicit present decision not to pursue.

Question:

> How do we preserve the future that was opened while truthfully recording that it is not being carried forward now?

Output:
- retirement/refusal candidate;
- reason;
- evidence refs;
- no deletion.

## Future chambers

Possible later chambers:
- INVERT — turn a repeated failure shape into an explicit design constraint;
- SPLICE — join two independently admitted organs through a versioned adapter;
- CULTURE — replay one mutation family across multiple census cuts to observe evolution;
- DREAM — model-assisted proposal generation behind the already-proven deterministic boundary.

None are part of SENSE-001.
