## Reproduce

Requires Python 3.12 or newer and a native, trusted Free Graph source checkout.

    python3 scripts/relay001_planz.py --graph /path/to/relay001.free-graph.json --free-graph-core /path/to/free-graph/scripts/fg_core.py --output /tmp/relay001-plan-offer.json

The output's content address binds the full mission offer, source packet ID, candidate census, and no-execution restrictions. Its verifier reconstructs the offer, rather than accepting any self-rehashed JSON. Native synthetic tests check false permission, wrong media, altered graph identity, and unchanged original graph.
